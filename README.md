# Kikitori Reader Mobile Latest

個人用の文書読み上げPWAです。スマートフォンとPCのブラウザーで動作します。

## 主な機能

- PDF、DOCX、EPUB、TXT、Markdownの読込
- 文章の直接貼り付け
- 日本語・英語の自動判定
- 端末内蔵音声による読み上げ
- 声、速度、文字サイズの変更
- 再生位置の自動保存
- スリープタイマー
- PWAとしてホーム画面へ追加
- スマホ用「本棚／読む」画面切替
- 画面下部に常時表示される再生操作
- 本棚検索
- 文書はブラウザー内のIndexedDBへ保存

## 起動方法

PWAとファイル読込はHTTP環境が必要です。ファイルを直接ダブルクリックせず、次のいずれかで起動してください。

### Windows / macOS / Linux

Pythonがある場合:

```bash
cd kikitori-reader
python -m http.server 8080
```

ブラウザーで `http://localhost:8080` を開きます。

### インターネット上に公開して携帯で使う

フォルダー全体をNetlify Drop、Cloudflare Pages、GitHub Pagesなどの静的ホスティングに配置します。公開URLをiPhoneのSafariまたはAndroidのChromeで開き、「ホーム画面に追加」します。

## 注意事項

- 音声の種類と自然さは、iPhone・Android・Windowsなど端末にインストールされている音声に依存します。
- 初回のPDF・Word・EPUB読込には外部ライブラリ取得のためインターネット接続が必要です。読み込んだ文書とアプリ本体は端末内に保存されます。
- 画像だけのスキャンPDFにはOCRが必要なため、この版では文字を取得できません。
- ブラウザーの仕様により、画面ロック中の長時間連続読み上げが端末によって停止する場合があります。
- 同期機能は搭載していません。文書と再生位置は利用した端末ごとに保存されます。

## データ削除

アプリ内の「すべて削除」またはブラウザーのサイトデータ削除で消去できます。

Kikitori Reader 起動方法

1. ZIPを右クリックして「すべて展開」してください。
2. 展開したフォルダーの「START_WINDOWS.bat」をダブルクリックしてください。
3. Windowsの警告が出た場合:
   「詳細情報」→「実行」を選択してください。
4. 黒い画面はアプリ使用中に閉じないでください。

通常起動できない場合:
「OPEN_DIRECTLY.bat」または「index.html」をダブルクリックしてください。
直接起動ではホーム画面追加やオフライン機能の一部が使えない場合がありますが、
テキスト貼り付けと読み上げは利用できます。

注意:
ZIPの中から直接START_WINDOWS.batを実行せず、必ず先に「すべて展開」してください。
